# Narcos: Dealer (Fabric 1.20.1)

## Как получить готовый мод (без установки программ)
1. Зарегистрируйся на github.com и создай новый репозиторий (New repository).
2. Загрузи туда все файлы из этого архива (Add file → Upload files). Папка `.github` тоже должна попасть.
3. Открой вкладку **Actions**: сборка запустится сама (3–5 минут). Если не запустилась, нажми Run workflow.
4. Когда появится зелёная галочка, открой запуск и внизу скачай **narcos-mod** (zip с .jar внутри).
5. Если красный крестик: открой лог, скопируй ошибку и отправь её мне, я исправлю.

## Как играть
1. Установи Fabric Loader для 1.20.1 (fabricmc.net) и скачай Fabric API 0.92.2+1.20.1 (Modrinth).
2. Положи Fabric API и narcos-1.0.0.jar в папку `mods`.
3. ВАЖНО: большие деревни работают только в НОВОМ мире.

## Команды
/biz — твой бизнес, /biz hire courier, /biz hire artist, /biz color red|blue|green|black,
/bail — залог в тюрьме, /heat <0-100> — тест (нужен оператор).
