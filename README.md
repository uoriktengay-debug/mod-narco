# Narcos: Dealer (Fabric 1.20.1)

## Как получить готовые моды
1. Открой GitHub → Actions и дождись зелёной галочки после сборки.
2. Скачай два артефакта: `narcos-main` и `narcos-expansion`.
3. Распакуй каждый архив. Положи оба файла `.jar` в папку `mods`.

## Установка
1. Установи Fabric Loader для Minecraft 1.20.1.
2. Установи Fabric API 0.92.2+1.20.1.
3. Положи `narcos-1.0.0.jar` и `narcos-expansion-1.0.0.jar` в папку `mods`.
4. Дополнение требует основной мод Narcos: Dealer.

## Поселения в Narcos: Expansion
Дополнение генерирует новые районы только в новых/ещё не обжитых чанках нового мира:
- столица у мирового спавна — район 1344×1344 блоков;
- город примерно в 1800 блоках от столицы — район 128×128;
- село примерно в 3000 блоках от столицы — район 64×64.

Площадь столицы примерно в 110 раз больше площади города. Столица строится плотной многоэтажной застройкой, город — среднеэтажными жилыми домами, село — небольшими домами на 1–2 этажа. Дороги, тротуары, фасады и окна собираются из блоков Minecraft, поэтому отдельные текстурные паки не нужны.

Команда `/biz location` показывает текущее поселение, названия трёх поселений и расстояния до них.

**Важно:** для полного результата создай новый мир. Уже обжитые чанки дополнение не перестраивает.

## Команды основного мода
`/biz` — бизнес, `/biz hire courier` — нанять доставщика, `/biz hire artist` — нанять граффитчика, `/biz color red|blue|green|black`, `/bail`, `/heat <0-100>` (нужен оператор).
