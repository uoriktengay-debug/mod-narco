# Narcos: Dealer (Fabric 1.20.1)

## Как получить готовые моды (без установки программ)
1. Открой вкладку **Actions** в репозитории.
2. Выбери последний запуск с зелёной галочкой.
3. Внизу скачай артефакт **narcos-mods** — внутри будут два отдельных .jar.
4. Если сборка красная: открой лог ошибки и отправь его мне.

## Как играть
1. Установи Fabric Loader для Minecraft 1.20.1 и Fabric API 0.92.2+1.20.1.
2. Положи **оба файла** в папку `mods`:
   - `narcos-1.0.0.jar` — основной мод Narcos: Dealer.
   - `narcos-expansion-1.0.0.jar` — дополнение. Оно требует основной мод и отдельно без него не запускается.
3. Запусти игру на Fabric 1.20.1 с Java 17.
4. Дополнение добавляет лабораторные блоки, контракты учёных, конкуренцию за клиентов: у постоянного поставщика клиента отобрать сложнее, но возможно, названия/типы поселений, новые многоэтажные здания с жильцом и систему высшей меры наказания. Высшая мера срабатывает при 10-й судимости, если игрок продал не менее 500 единиц товара. Для полного набора новых зданий лучше создать новый мир.

## Команды
/biz — твой бизнес, /biz hire courier, /biz hire artist, /biz color red|blue|green|black,
/bail — залог в тюрьме, /heat <0-100> — тест (нужен оператор), /network — статистика продаж и клиентов.
